# LangChain Models Repository

Welcome to the **LangChain Models** repository by [vikas-kashyap97](https://github.com/vikas-kashyap97).  
This repository provides a modular and extensible collection of implementations and examples designed for working with **Large Language Models (LLMs)** and **Retrieval-Augmented Generation (RAG)** using the [LangChain](https://github.com/vikas-kashyap97/langchain_models.git) framework.

---

## 📦 Key Modules Overview

### 1. `LLMs`  
Examples and utilities for interacting with foundational Large Language Models.

### 2. `ChatModels`  
Modules tailored for chat-based LLMs, enabling conversational AI capabilities.

### 3. `EmbeddedModels`  
Implementations of embedding models used for vector search, semantic similarity, and other retrieval-based tasks.

### 4. `Prompt`  
Best practices and reusable utilities for crafting effective prompts within LangChain workflows.

### 5. `Structured and Unstructured Outputs`  
Examples demonstrating how to manage and utilize both structured and unstructured outputs from LLMs.

### 6. `Output Parsers`  
Tools for parsing, validating, and transforming outputs generated by LLMs into structured formats.

### 7. `Chains`  
Implementations of LangChain’s chain components used to build multi-step LLM pipelines.

### 8. `Runnables`  
Modular building blocks that define and execute individual steps in a LangChain-driven process.

### 9. `RAG Components`  
Modules dedicated to **Retrieval-Augmented Generation (RAG)**, including:
- Tool calling examples
- Integration with retrievers and vector stores
- Sample RAG workflows
